# KelanaAI

KelanaAI adalah aplikasi AI Travel Planner yang dibangun bertahap selama 12 sesi.

## Sesi 1 — Trip Summary Generator (Console App)
Fitur pertama: aplikasi konsol Python untuk input data perjalanan dan menampilkan
ringkasan perjalanan (trip summary), termasuk estimasi biaya.

### Cara Menjalankan
```bash
cd backend
python main.py
```
